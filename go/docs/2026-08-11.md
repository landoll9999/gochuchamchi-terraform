## 1. workload-admin SSO 프로파일 구성과 tfstate 부트스트랩

### 작업 목적

IAM Identity Center 프로파일(`workload-admin`)을 만들고 `scripts/bootstrap-state.ps1 -Account workload`로
tfstate 버킷(`gochuchamchi-tfstate-828885965304`)을 최초 1회 생성한다.

### 문제가 발생한 지점

- **1.1** `aws sso login --profile workload-admin` → "config profile could not be found".
  프로파일 자체가 없었음 → `aws configure sso`로 생성. MFA 등록의 "휴대폰으로 QR 스캔" 화면은
  "다른 옵션 → 이 디바이스(Windows Hello)"로 휴대폰 없이 통과.
- **1.2** 스크립트 실행이 "디지털 서명되지 않았습니다"로 차단 — ZIP으로 받은 저장소라
  전 파일에 Mark of the Web이 붙어 RemoteSigned 정책에 걸림.
- **1.3** 차단을 풀자 이번엔 스크립트가 PS 5.1과 비호환 — `2>$null` 리다이렉트가
  "버킷 없음(404)"이라는 정상 응답을 종결 오류로 승격시켰고, 그 다음엔 JSON 인자의
  큰따옴표가 유실되어 `Invalid JSON`.
- **1.4** 원본 스크립트 자체 버그 — `put-public-access-block` 인자를 불필요한
  `PublicAccessBlockConfiguration` 키로 감싸고 있어 **PowerShell 7에서도 실패했을** 코드.

### 문제 원인

상세는 종합본 §1·§2. 요약: ZIP 배포 + PS 5.1 전용 함정 3종(오류 승격 / 인자 따옴표 유실 /
BOM 없는 UTF-8 한글 깨짐) + 원본 래퍼 키 버그.

### 해결 방법

- `Unblock-File`로 저장소 전체 차단 해제 (실행 정책 자체는 RemoteSigned 유지).
- `bootstrap-state.ps1`을 PS 5.1/7 양쪽 호환으로 수정: JSON은 `file://` 임시 파일로 전달,
  head-bucket은 `cmd /c` 경유, 래퍼 키 제거, UTF-8(BOM) 저장.
- 스크립트 수정 전에 버킷은 동일 설정으로 AWS CLI 직접 실행해 먼저 생성해 둠.

### 검증 완료 사항

- get-bucket-versioning / get-public-access-block / get-bucket-encryption / get-bucket-policy로
  4종 설정(버저닝 · 퍼블릭 차단 4항목 · SSE-S3 · TLS 강제) 전부 확인.
- 수정한 스크립트를 PS 5.1에서 재실행 — "기존 tfstate 버킷 사용" 경로로 멱등 통과, 한글 정상 출력.

## 4. Image Updater ECR 인증 마비 — CRLF가 파괴한 셔뱅 (오늘의 핵심)

### 작업 목적

`fork/exec /scripts/ecr-auth.sh: no such file or directory`가 2분마다 반복 —
이대로면 이미지 자동 갱신(write-back)이 영구 정지라 수동 커밋 없이는 배포가 안 돈다.

### 문제 원인 · 진단이 어려웠던 이유

"no such file"인데 **파일도, `/scripts` 마운트도, ConfigMap도 전부 존재**했다.
`fork/exec` ENOENT는 대상 파일 부재만이 아니라 **셔뱅의 인터프리터 부재**도 가리킨다는 것이
분기점 — ConfigMap 내용을 바이트 단위로 찍어 보니 `#!/bin/sh<CR><LF>`.
argocd.tf의 heredoc이 **clone 시 autocrlf로 CRLF가 된 .tf 파일**에서 렌더링되면서
커널이 `/bin/sh\r`라는 존재하지 않는 인터프리터를 찾고 있었다.
구계정에서 정상이었던 이유: 그땐 LF 체크아웃에서 apply했기 때문. **8/5 §1에서 만든
`.gitattributes`가 §7에서 삭제(회귀)된 대가를 오늘 인프라 장애로 치른 셈.**

### 해결 방법

`argocd.tf`의 `ecr-auth.sh` heredoc을 `replace(…, "\r\n", "\n")`로 감싸 어떤 체크아웃
설정에서도 LF를 보장. plan 검토(helm_release in-place 1건 + 상시 게이트 3건 + 앱
타깃그룹 경보 2건 신규 — 전부 예상 범위) 후 apply.

### 검증 완료 사항

- 컨트롤러 로그 `images_updated=1, errors=0` — 에러 반복 종료.
- Image Updater가 gitops에 write-back 커밋(`build: automatic update of gochuchamchi`) 생성 확인
  — 자동 갱신 체인 완전 복구.
