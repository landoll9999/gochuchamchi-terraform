### 새 날짜 파일 작성 형식

```markdown
# YYYY-MM-DD 작업 기록

## 1. <한 줄 제목>

### 작업 목적
### 문제가 발생한 지점
### 문제 원인
### 해결 방법
### 검증 완료 사항
```

- 하루에 여러 건이면 `## 1.`, `## 2.` … 로 건별 번호를 붙이고, 세부 이슈는 `### 1.1`, `### 1.2` 로 나눕니다.
- 같은 이슈가 나중에 재발하면 `### 1.2-1`, `### 1.2-2` 처럼 하위 번호로 이어 붙입니다.
- 재사용 가치가 있는 교훈은 [pitfalls-checklist.md](pitfalls-checklist.md)에도 한 줄 추가합니다.
- 작성 후 위 표에 최신 날짜를 맨 위로 추가합니다.
